# Hero Studio

**Status:** Planned: empty scaffold.

The local web interface: `hero-cloud studio` serves it on `127.0.0.1` and opens it in the browser. A guided flow takes a person from "here is my app" to "here is your URL", with the explanation depth chosen by the reader (`simple`, `guided`, `expert`).

Studio runs on the user's machine against the user's AWS account and AI. It is not the public website (`apps/web`) and has no accounts. It talks only to the local server. See [docs/ARCHITECTURE.md](../../docs/ARCHITECTURE.md#doors).
