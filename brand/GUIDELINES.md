# Hero Cloud brand

Hero Cloud uses a retro handheld-game visual language with readable modern information architecture. The primary wordmark gives `HERO` equal importance to `CLOUD`: vivid yellow and bright blue with a dark navy pixel outline. Blue, yellow, red cape accents, pixel clouds, stars, and speed lines are approved web motifs.

Hero Cloud is an open-source project sponsored and initially maintained by Cloud Republic. It is not an AWS reseller and is not a Cloud Republic-managed hosting service.

The source brand kit is in `apps/web/public/brand/hero-cloud-brand-kit.png`. Do not imply AWS endorsement or change the wordmark proportions.
