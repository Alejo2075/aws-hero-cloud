# Brand source

Hero Cloud uses a retro handheld-game visual language with pixel typography, vivid yellow and blue, dark navy outlines, and red cape accents. Product and repository wording must make clear that Hero is open source, AWS-first, and not an AWS reseller.

The working web asset is currently stored at `apps/web/public/brand/hero-cloud-brand-kit.png`. Add source logos and decorative exports here as the brand library grows.

See also [GUIDELINES.md](GUIDELINES.md) for name usage, logo rules, and what not to do.
