# MCP server

**Status:** Planned: empty scaffold.

Exposes the SDK to AI agents and coding assistants through the Model Context Protocol, so a user's own AI can analyze, plan, and explain a deployment.

Agents can read and propose; they cannot approve. There is no approve tool: a deploy request is handed to a person through a channel the agent cannot answer. See [docs/ARCHITECTURE.md](../../docs/ARCHITECTURE.md#doors).
